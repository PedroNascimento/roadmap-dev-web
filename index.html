Guia prático · atualizado em setembro de 2026

Do primeiro comando ao deploy.

Uma rota progressiva para aprender programação, dominar a web, construir projetos públicos e chegar a uma stack profissional — sem tentar estudar tudo ao mesmo tempo.

12–18 meses sugeridos 10–15 h por semana 14 fases projetos em todas as etapas

A rota recomendada

Construa uma camada por vez. Java entra depois que a base web e de back-end estiver firme.

02

Regra de avanço: você não precisa saber 100%. Avance quando conseguir explicar, implementar e depurar um projeto pequeno sem copiar um tutorial inteiro.

Ambiente de estudo recomendado

Comece com ferramentas simples, populares e bem documentadas. O objetivo é reduzir atrito e aprender conceitos transferíveis.

setup inicial
Sistema operacional

Pop!_OS 24.04 LTS

1ª recomendação: amigável para iniciantes, baseado no ecossistema Ubuntu, com ambiente COSMIC e imagem específica para computadores com NVIDIA. 2ª recomendação: Fedora Workstation, ideal para quem prefere GNOME e tecnologias mais recentes.

IDE principal

VS Code

Use para HTML, CSS, JavaScript, TypeScript, Git e Node.js. Instale poucas extensões: Prettier, ESLint, GitLens e a extensão da linguagem usada no momento.

IDE para Java

IntelliJ IDEA

A edição Community cobre Java e Maven/Gradle. Para Spring avançado, avalie Ultimate apenas quando houver necessidade real. VS Code com Extension Pack for Java também funciona.

Kit mínimo: Pop!_OS como primeira opção ou Fedora Workstation como segunda, Firefox + Chromium, VS Code, Git, GitHub CLI (opcional), Node.js via gerenciador de versões, Docker apenas a partir da fase de banco/back-end e IntelliJ quando começar Java. Não transforme a configuração do ambiente em um curso sem fim.

Qual stack escolher depois dos fundamentos?

Escolha uma rota principal por pelo menos seis meses. Profundidade vence uma coleção de tutoriais.

decisão prática
Entrada mais suave

Front-end

Para quem gosta de interface, feedback visual e experiência do usuário.

  • HTML + CSS + JavaScript
  • TypeScript + React + Vite
  • React Router + TanStack Query
  • Vitest + Testing Library + Playwright
  • Netlify para deploy
Recomendação principal

Full-stack TypeScript

Uma linguagem no navegador e no servidor reduz o custo cognitivo no início.

  • React/Next.js no front-end
  • Node.js + Fastify; NestJS depois
  • PostgreSQL + Prisma/Drizzle
  • OpenAPI + testes de integração
  • Docker + CI/CD
Especialização posterior

Java + Spring

Excelente para back-end robusto, sistemas de longa vida e mercado corporativo.

  • Java LTS + Maven
  • Spring Boot + Spring Web
  • Spring Data JPA + PostgreSQL
  • Spring Security + Actuator
  • JUnit + Mockito + Testcontainers
Sequência que evita confusão: JavaScript → TypeScript → React → HTTP/API → PostgreSQL → Node → projeto full-stack. Depois escolha: aprofundar Node/Next ou abrir a trilha Java/Spring. Não estude React, Angular, Vue, Node, Java e Python ao mesmo tempo.

Desenvolvimento assistido por IA

Use IA como par de programação e instrumento de aprendizagem — não como substituto da compreensão.

desde a fase 1
Antes de gerar

Defina o problema

Escreva requisitos, exemplos, restrições e critérios de aceite. Peça um plano pequeno e confirme suposições antes de pedir código.

Durante

Trabalhe em diffs pequenos

Forneça arquivos relevantes, peça uma mudança por vez, rode o código, leia o diff e solicite testes para comportamentos importantes.

Depois

Verifique tudo

Compile, teste, consulte a documentação oficial, faça revisão de segurança e explique a solução com suas palavras antes do commit.
