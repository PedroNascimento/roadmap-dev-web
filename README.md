# Roadmap Dev Web

Documento interativo e responsivo para quem está começando em tecnologia e deseja evoluir até o desenvolvimento web profissional, com trilha opcional de Java e Spring.

## Abrir localmente

Abra `index.html` em qualquer navegador moderno. Não há etapa de build nem dependências.

## Publicar no Netlify

### Opção 1 — GitHub (recomendada)

1. Crie um repositório no GitHub e envie estes arquivos.
2. No Netlify, escolha **Add new project → Import an existing project**.
3. Conecte o repositório.
4. Deixe o comando de build vazio e use `.` como diretório de publicação.
5. Publique. Novos pushes farão deploy automático.

### Opção 2 — Netlify Drop

Arraste a pasta `roadmap-dev-web` para <https://app.netlify.com/drop>.

## Funcionalidades

- Filtro por trilha e busca por conteúdo.
- Fases expansíveis.
- Checklist com progresso salvo em `localStorage`.
- Tema claro e escuro.
- Layout responsivo e navegação por teclado.
- Impressão e exportação para PDF pelo navegador.
